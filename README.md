# TravelTide Customer Segmentation

A customer analytics portfolio project exploring travel behavior and segmentation using Python and K-means clustering.

## Project objective
The notebooks examine customer and booking behavior, prepare analytical features, and experiment with customer segments that can support more targeted travel offers and retention analysis.

## Repository contents
- `TravelTide.ipynb` — exploratory work.
- `TravelTide_Finish.ipynb` — completed analysis workflow.
- `TravelTide_Kmeans_Cluster.ipynb` — K-means segmentation work.

## Workflow
1. Inspect and prepare the available TravelTide data.
2. Explore customer and travel behavior.
3. Engineer features suitable for segmentation.
4. Apply K-means clustering.
5. Interpret the resulting segments in business terms.

## Tools
Python · pandas · Jupyter Notebook · exploratory data analysis · K-means clustering

## Reproducibility note
The repository currently contains the analysis notebooks but not a standalone dataset or dependency file. Results should therefore be interpreted in the context of the notebook execution environment and the data used when the notebooks were created.

## Portfolio improvements
Future work can add a documented dataset source, a requirements file, saved visual outputs, cluster-validation metrics, and a concise segment-to-action table.
